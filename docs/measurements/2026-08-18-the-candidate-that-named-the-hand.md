# The candidate that named the hand, and the copy that was read in the wrong alphabet

*2026-08-18 · the second-printing question, third time of asking, put as a test*

---

## What was asked

A previous session established that the printing every rule in
`out/textual/significator-series-rules.jsonl` resolves into carries a **second commenting
hand**: a voice that names the translator in the third person, says his notes are not clear,
and claims books of its own. It could not be named from that copy, which has no title page,
no imprint and no preface — and naming it from the books it claims would have supplied an
authorship out of the recorder's memory, the unsourced claim this discipline exists to
refuse.

That left a standing refusal with a stated test attached to it: **acquire a printing of the
same translation, search it for the twelve spellings that mark the second hand, and require
zero over the whole copy.** The test came with its own warning, because the copy acquired to
try it was 219 pages of images and passed it perfectly by being blank.

Two candidates were acquired from a public archive this session. **Neither passes, and the
two failures are different in kind.** Only one of them is about a book.

---

## Candidate one — the printing that declares itself the fifth

It fails the test outright: **all twelve spellings occur in it, 215 times.**

And it says why, in its own words, each resolving exactly once:

* a title page reading *"Revised and Annotated by BANGALORE VENKATA RAMAN, Editor, The
  Astrological Magazine"*
* an imprint reading *"Fifth Edition 1955"*
* a signed foreword presenting *the fifth and revised edition of the English translation of
  the first two adhyayas*

So it cannot witness the translator's unrevised words either, and the standing refusal
stands. **That is the most useful thing this candidate could have done**: it fails for a
reason that is a property of the printing rather than of the reading, and it says so on its
own page.

---

## Candidate two — and it is the trap wearing a different face

Eleven of the twelve spellings return **zero** over it. The twelfth — the printed asterisk,
the only one of the twelve that is not a word — returns 128. **Scored on the count alone this
copy misses a clean pass by one punctuation mark.**

It returns those zeroes because its machine reading carries **246 777 searchable characters
and not one letter of the Latin alphabet.** It is a scan of an English printing read by a
machine set to an Indic script: a quarter of a million characters of noise.

⛔ **Every guard this repository owned before this session passes it.** It is not missing. It
is not out of extent. It is emphatically not mute — the mute-copy refusal armed last session,
which fires on 219 blank pages, does not fire here at all.

> **A copy that was read, in the wrong alphabet, is strictly more dangerous than a copy that
> was never read.** The blank copy fails every check that asks whether anything was read. This
> one passes all of them, and still returns zero for every English word in an English book.

---

## And the guard armed last session does not catch it either

Last session armed both absence instruments to require a **positive control resolving exactly
once** before any zero could be written. Over this copy a control is free:

| fragment length | the copy of noise | a copy that is a book |
|---|---|---|
| 8 characters | **300 / 300** resolve exactly once | 129 / 300 |
| 10 | 300 / 300 | 183 / 300 |
| 12 | 299 / 300 | 219 / 300 |
| 16 | 299 / 300 | 269 / 300 |
| 20 | 300 / 300 | 291 / 300 |

*(the first 300 distinct runs of each length in document order, per copy — a cap, stated)*

Nothing in a noise rendering repeats, so **the condition this repository leans on hardest is,
in that one copy, the easiest in the file to satisfy.** A dozen characters of the copy's own
noise resolve exactly once, satisfy the control, and license a twelve-spelling absence in an
alphabet the rendering contains none of.

---

## What is armed

Both refuse a row that could actually be built, on a copy actually held.

* **A rendering must carry the script the searched alphabet is written in.** This refuses the
  library scan. `AbsenceSearch` refuses it before the control is even looked at, because a
  control cannot repair it.
* **A positive control must be written in that same script.** This refuses a Latin-alphabet
  absence over the Hindi copy — which carries 196 380 Devanagari letters *and* 8 959 Latin,
  so it passes the script-presence check — guarded by a Devanagari control that resolves
  exactly once. A control proves the copy was read *in the script the control is written in*
  and nothing more.
* **`PassageAbsence` checks the script before attestation**, for the same reason the mute
  check was moved there last session. Over a wrong-script rendering every Latin spelling is
  genuinely unattested, so the attestation rule fires and reports that the recorder *guessed*
  the vocabulary — sending the next reader to fix a vocabulary that was never the problem.

> ⚠ **The fix that named the right cause was written for one cause, and the wrong cause has
> more than one.** Last session moved a check ahead of attestation because a blank copy made
> attestation blame the reader. A noise copy does it again, by a different route, and the
> earlier fix does not reach it.

### The script bucket had to be defined over letters, and that is not tidiness

Written as a bare code-point range, the Latin bucket reported **6 077 Latin characters in the
copy that contains no Latin letter.** Every one of them was a brace, a bracket, or a sign
that happens to live inside the Latin block — 3 432 of them the character `{`. The guard
built to catch that copy would have passed it.

> **A bucket that counts a rendering's punctuation as its script answers yes for exactly the
> copy the question was asked about.** The bucket now requires a character to be a letter, and
> the artifact carries both numbers, because the pair is the finding.

---

## The finding the test was not asking for

**The hand this repository could not name is named — on another copy's page.**

The naming copy's title page and its signed foreword both name it. The earlier refusal is
discharged in the only way it could be: from a page, not from the recorder's memory.

⛔ **A name in one copy is not the hand in the other until something located ties them**, and
the tie is required. Ten candidate fragments were tried — the five located rule fragments and
the five second-hand passages, each resolving exactly once in the copy in hand. **One
resolves exactly once in the naming copy too**: the second hand's own claim of a book, the
very claim the earlier session refused to turn into a name, now doing the work honestly
because the other copy prints the name.

**The other nine resolve zero times there — and not one of them is absent.** All nine are on
the page in both printings; the two machine readings spell them differently. A letter read as
a digit, a word hyphenated across a line break, a quotation mark invented.

> **A fragment that resolves in one machine reading and not in a second machine reading of the
> same words measures the two readings, not the two printings.** A recorder scoring those nine
> as *the naming copy does not contain the rules* would have published nine absences with
> complete confidence.

---

## The foreword disagrees with itself, and the sentence that does so is the one that mattered

One signed foreword, one paragraph apart:

> *"I have not meddled with either the translation or the notes as given by Prof. Rao for fear
> of aifecting the sense."*

> *"The Translation herewith presented has been tho- roughly revised by me."*

Neither is doubted here and neither is adopted. **The pair is what is published.**

⛔ The first sentence is precisely the one that would have retired this file's standing
refusal. A recorder who took it would have retired a refusal on the strength of a claim the
same hand contradicts a paragraph later.

> **A reviser's own account of what he changed is not evidence of what he changed** — measured
> rather than argued, because this one disagrees with itself in a single paragraph.

### And it retires an inference published here last session

Last session read the copy in hand's scoped disclaimer — *"I have not meddled with the English
rendering of **this** sutra"* — as evidence of alteration elsewhere: *a disclaimer scoped to
one sutra is worth making only by a hand that alters others.*

The copy that kept its front matter **makes the same disclaimer generally**, in the foreword,
about the translation and the notes as a whole. The scoped one is a repetition, not a
contrast. ⭐ *The inference looked compelling because the copy in hand had lost the general
statement along with its front matter.* The refusal it supported stands on other ground — that
hand's own foreword contradicts itself — but the inference is withdrawn.

---

## What is still not established

**Which printing the copy in hand actually is.** It carries no title page, no imprint and no
foreword; *edition*, *Preface*, *Copyright*, *Publisher*, *Published* and *Printed* all occur
zero times in it. A printing that names itself has now been acquired, and matching the two by
their words does not settle it either — one of ten located fragments crosses, and the nine
failures are OCR difference. Refused, by name.

**And no candidate has passed the test.** Three copies, three sets of zeroes, three different
reasons, and only one of them is about a book.

## Reproducing

```
python generators/r6_karaka_rules.py --acquire --out out
python generators/r6_karaka_rules.py --out out
```

The first goes to the network and dates each retrieval beside the copy; the second reads only
what is on disk and produces the same bytes every time. Twelve controls, all held. Re-emitted
by row identity rather than by position: **30 rows byte-identical, 0 changed, 10 added, 0
removed** — every rule, every corroboration, the correction, the alignment and every standing
refusal untouched.

⛔ No machine reading was produced here. An absence over our own optical reading would be an
absence over our own mistakes; every rendering used is the distributor's.
